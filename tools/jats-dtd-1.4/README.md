# JATS 1.4 Archiving DTD

The files in this directory are the official JATS 1.4 Journal Archiving and Interchange DTD with MathML3,
fetched on 2026-11-12 from the National Library of Medicine (NLM):
https://public.nlm.nih.gov/projects/jats/archiving/1.4/JATS-Archiving-1-4-MathML3-DTD.zip

The DTD is NLM public-domain material. Do not edit the vendored DTD, entity, module, or catalog files.
