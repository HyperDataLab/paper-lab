## Data table space (owner request, same day)

Reference: SciSpace Extract Data — up to 50 columns including the suggested ones; custom columns with a name and
instructions; every cell traceable to its page; export RIS, CSV, BIB, Excel, XML ([SciSpace](https://scispace.com/extract-data)).

PaperLab's Extraction module already has the 50 suggested columns with the same names, custom columns with
instructions and type, Standard / High quality runs, cell evidence with page and quote, review history, and CSV/JSON
export. **Decision:** the Data table space reuses that engine for the open paper — one row per column (Column · Value
· Sources), a Column settings panel with the suggested columns by group and custom ones, a cap of 50, exports CSV,
Excel, BibTeX, RIS and JSON, and "So sánh với bài khác" to add the paper to an Extraction project. It is entered from the
page-level switch (C1). Slice R17, after R14–R15.
