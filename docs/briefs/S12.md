## 1. Core — `src/core/report/`

- `buildAnalysisReport(analysis, { audit, revisions, generation, parent })` → `AnalysisReport`: source text and hash,
  offset unit, tokenizer / segmenter / prompt / model / rubric / detector versions, `context_limited`, sentences with
  T/A/S and roles, paragraph structure and flow, metrics with denominators, scores (with coverage, confidence, rubric,
  suppressed reason), issues grouped by category with status, spans as quoted text + offsets, human decisions from the
  audit log, revisions and generation provenance, and a "Giới hạn" section (rubric uncalibrated, scores are not
  scientific validity, AI judgements vary between runs).
- `toJsonReport(report)`: stable key order, `format: 'paragraph-lab-report'`, `formatVersion: 1`; validated with a Zod
  schema; **not** importable (the S3 package stays the import format — say so in the file).
- `compareAnalyses(a, b)` for two analyses (typically source and an applied revision): text diff (S10 `alignRevision`),
  metric deltas (each with both values and denominators), score deltas per dimension (only where both applicable), issues
  resolved (in a, not in b by type + quoted text), persisting, new; and the same `checks` as S10 between the texts.

## 2. UI

- Evaluate (saved analysis) and History rows: `Xuất báo cáo` menu → `JSON (.json)` (download via Blob, file name
  `paragraph-lab-report-<shortId>-<date>.json`) and `Bản in / PDF` (opens `/report/:id`).
- `/report/:id`: a print-optimised page (`@media print`: no sidebar/toolbar, A4 margins, page breaks before major
  sections, colours + line styles survive greyscale, links printed as text) with a "In / Lưu PDF" button
  (`window.print()`); sections: Thông tin & phiên bản, Văn bản gốc (highlights as underline styles with a legend and
  numbered footnote markers), Câu (T/A/S, vai trò), Cấu trúc đoạn & mạch, Số liệu, Điểm (never a bare number), Vấn đề
  (with status and human decisions), Bản sửa / nguồn soạn, Giới hạn.
- `/compare?a=<id>&b=<id>`: version comparison (from History: select two analyses, or "So sánh với bản gốc" on a
  revision): side-by-side text diff, metric and score delta tables (arrows + numbers, not colour only), issues
  resolved / persisting / new, meaning checks.
- `DESIGN.md`: document report and compare views. `docs/ROADMAP.md`: S11 ✅, S12 🟨.
