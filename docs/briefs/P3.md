## 1. Core — `src/core/paperOverview/`

- `aggregatePaper(paper, analyses)` → `PaperOverview` (Zod):
  - per section (in paper order): `bodyParagraphs`, `analysed` (paragraphs with an analysis), `coverage` (fraction,
    3 decimals); open issues by category and by type (open = `candidate`, `confirmed_by_model`, `confirmed_by_human`;
    excluded: `dismissed_by_human` and AI-acceptable `info`); per S9 dimension the distribution of applicable paragraph
    scores `{ n, median, q1, q3, min, max }` (null when n = 0); paragraph-structure type counts from S8 results.
  - paper-level: the same counts over all sections, with `coverage = analysed / bodyParagraphs`; a
    `recurringIssues` list: issue types that occur in ≥ 3 paragraphs or in ≥ 2 sections, each with paragraph ids, section
    ids, count and up to 3 example quotes (quoted from the stored spans).
  - `generatedFrom`: analysis ids, their `updatedAt`, and the prompt / rubric versions seen (to detect staleness).
- `transitionPairs(paper, analyses)`: consecutive **body** paragraphs inside the same section (skip other kinds) where both
  have S5 annotations; for each pair the last sentence of the first paragraph (its stress span) and the first sentence of
  the second (its topic span), quoted by code.

## 2. Transition judgement — new prompt and batch step

- `src/core/prompts/paragraphTransition.ts`: `PROMPT_VERSIONS.paragraphTransition = 'para-flow-1'`; input lists pairs as
  `pairId | section role | "last sentence of P" (stress: "…") → "first sentence of P+1" (topic: "…")`; output per pair
  `{ pairId, continuity: 'stress_to_topic'|'topic_to_topic'|'derived'|'shift', discourseRelation (S8 enum), linked,
confidence, rationale (Vietnamese) }`; same rules as S8: classify only, no offsets, `other` only with a named relation,
  `none` otherwise. At most 12 pairs per call.
- `validateTransitions(raw, pairs)`: unknown pair ids dropped, missing pairs → unmeasured (as in S8 R3).
- Findings (code): `FLOW_BREAK_CANDIDATE` for an unlinked shift with relation `none`/`other` and confidence ≥ 0.5,
  `UNEXPLAINED_TOPIC_SHIFT` for the weaker case — same rules as S8, but each finding references **two paragraphs**:
  `{ id, type, pairId, from: { paragraphId, analysisId, span }, to: { paragraphId, analysisId, span }, severity, status,
why, suggestedFix, confidence }` with Vietnamese texts naming the paragraph ids; human review statuses work on them.
- Batch: add the step `transitions` to `planRun` / `runBatch` (estimate `ceil(pairs / 12)` per selected section; needs
  syntax for both paragraphs — pairs without annotations are skipped with a reason); results saved to storage below.

## 3. Storage

Dexie version bump with a `paperOverviews` table: `{ paperId, overview, transitions: { pairs, findings, promptVersion,
model, updatedAt } }`; repository get / save; audit `review_transition` for human decisions on transition findings.
Export / import include `paperOverviews` (old exports still import). The overview is recomputed (cheaply, locally)
whenever paragraph analyses change; the transition judgement is only re-run by the batch step.

## 4. UI — tab `Tổng quan` on `/papers/:id` (next to the map)

- Header: "Đã phân tích N/M đoạn (x %)" and a stale notice when analyses changed after the transition judgement.
- Section table: section (role label + heading), coverage, open issues by category (numbers + small bars with numbers,
  not colour only), median score per dimension with `q1–q3` and `n` (e.g. "62,5 (50–75, n = 6)"), "Chưa đủ dữ liệu" when
  n = 0. No paper total and a permanent note: "Tổng quan chỉ thống kê kết quả các đoạn đã phân tích; không phải điểm đánh
  giá bài báo."
- Recurring issues: list with type label, count, sections, example quotes; clicking filters the map to those paragraphs.
- Transitions: per section the chain `P1 → P2 → …` with continuity / relation labels (Vietnamese, as in S8), linked /
  not linked (icon + text), quoted stress → topic; findings with Xác nhận / Bỏ qua / Hoàn tác; clicking a side opens that
  paragraph's analysis in Evaluate.
- The batch panel gains the step checkbox "Chuyển đoạn" with its estimate.
- `DESIGN.md`: document the overview tab. `docs/ROADMAP.md`: P2 ✅, P3 🟨.

## 5. Tests (IDs in names)

- `aggregatePaper`: coverage fractions; open-issue filtering (dismissed and `info` excluded); score distributions
  (median / quartiles on even and odd n, n = 0 → null); recurring-issue thresholds and example quotes; staleness fields.
- `transitionPairs`: same-section consecutive body paragraphs only, kinds skipped, pairs without annotations skipped.
- Prompt and validation: version, ≤ 12 pairs per call, unknown / missing pairs, `other` rule, findings with two
  paragraph references and deterministic ids; human decisions kept on re-run.
- Batch: `transitions` estimate and execution within the budget.
- Storage: migration, repository, export / import.
- UI (fake client): overview table numbers, "Chưa đủ dữ liệu", no total score anywhere, recurring issue click filters the
  map, transition chain with labels, confirm / dismiss a transition finding, stale notice.
- Coverage ≥ 90 % lines for `src/core/**` and `src/shared/llm/**`; all existing tests pass.
