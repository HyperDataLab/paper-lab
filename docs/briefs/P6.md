## 1. Core — `src/core/probe/`

- Prompt `src/core/prompts/styleProbe.ts`: `PROMPT_VERSIONS.styleProbe = 'style-probe-1'`, the system text verbatim from
  `docs/prompts/ai-review.md` §5; output schema `{ rewritten: string }`.
- `selectProbeParagraphs(paper, analyses, n, seed)`: body paragraphs that already have an S9 score with at least one
  applicable dimension; deterministic sample (seeded by paper id) spread across sections; default n = 5, max 10; fewer than 3
  eligible → plan refused with "Cần chấm điểm ít nhất 3 đoạn trước".
- Estimate per paragraph: 1 rewrite + 1 syntax on the rewrite + 1 score on the rewrite + 1 baseline re-score of the original
  = 4 calls (+ judge when the original analysis has a judgement = 5); shown before running; budget through the P2 request hook.
- `validateProbe(original, rewritten)`: runs S10 meaning checks; any `fail` (numbers, citations, negation, claim strength,
  terms) → the probe is **discarded** with its reasons and is not scored further; identical text → discarded ("không có thay
  đổi").
- Baseline noise: the original paragraph is re-scored once with the same inputs; `noise = |rescore − original|` per dimension,
  so a style effect can be told apart from test–retest variation of the model.
- `summariseProbe(items)` → per dimension and overall (applicable dimensions only, both sides applicable): `meanDelta` (signed,
  rewrite − original), `meanAbsDelta`, `meanNoise`, n; verdict: `insufficient` (< 3 valid probes), `style_sensitive` (|meanDelta| >
  max(5, 2 × meanNoise) on the overall or any dimension), otherwise `stable`. Direction is reported ("điểm tăng khi chỉ đổi văn
  phong"). Thresholds are named constants commented as product heuristics.

## 2. Provider and storage

`src/shared/llm/llmStyleProbe.ts`: orchestrates the calls above sequentially with retry and budget, whole-manuscript consent,
cancellable, checkpoint after each paragraph (resume). Dexie version bump with `paperProbes` (`{ paperId, runs: [{ id, createdAt,
n, promptVersions, model, items, summary }] }`); rewritten text is stored for audit only. Audit `run_probe`. Export/import include
`paperProbes` (newest wins), deleted with the paper.
