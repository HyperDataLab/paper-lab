## 1. Core — `src/core/paperChecks/`

- `runPaperChecks(paper)` → `PaperCheckReport = { version: 'checks-1', generatedAt, checks: CheckResult[] }` with
  `CheckResult = { id, label (Vietnamese), status: 'pass'|'warn'|'fail'|'not_applicable', experimental: true,
summary, findings: Finding[], falsePositiveNotes: string[] }` and `Finding = { id (deterministic), checkId, severity:
'info'|'minor'|'moderate', message (Vietnamese), locations: [{ paragraphId, start, end }] (code points in the
paragraph text), evidence: string[] }`.
- Checks:
  1. `citations_references` — in-text citations (numeric `[3]`, `[3, 5]`, `[3–6]`; author–year `(Smith, 2020)`,
     `(Smith et al., 2020a)`, `Smith and Lee (2019)`) vs. entries in reference paragraphs: cited but no matching
     reference (fail/moderate), reference never cited (info), numeric gaps or out-of-range numbers. Author–year matching
     by first-author surname + year (+ suffix letter); tolerate diacritics and "et al.".
  2. `figures_tables` — `Figure N` / `Fig. N` / `Table N` mentioned in body text vs. captions present; referenced but
     no caption (warn), caption never referenced (info), numbering gaps.
  3. `acronyms` — acronyms (2–8 capitals, optional digits/lowercase plural `s`) used before their definition `Long
Form (LF)` or never defined (minor); defined twice with different expansions (minor). Ignore common ones
     (e.g. AI, LLM, DNA, RNA, PCR, USA, UK, EU, CI, SD, SE, ID, PDF, URL) via an editable list in the module.
  4. `numbers_consistency` — numbers with units / percentages stated in the Abstract (and Conclusion) that do not appear
     anywhere in Results/Discussion/tables captions (warn), using the S10 number-with-unit extraction; and the same
     quantity name with different values (best effort: same unit + same 3-word context → warn).
  5. `claim_strength_drift` — certainty words (`demonstrate(s|d)`, `prove(s|d)`, `establish(es|ed)`, `clearly`,
     `definitely`, `always`, `significantly` without a statistic nearby) in Abstract/Conclusion while the Results /
     Discussion paragraphs on the same topic use hedges (`may`, `might`, `suggest`, `likely`, `preliminary`): warn with
     both locations (topic match = shared content words ≥ 2 within the sentence).
  6. `unsupported_claims` ("illusion of thoroughness", App. E.1 of the reference paper) — sentences claiming an
     ablation, theorem/proof, statistical significance, state-of-the-art, or "extensive experiments" with no figure /
     table reference, citation or statistic (p-value, CI, ±, n =) in the same or next sentence (warn); a "Theorem N"
     with no "Proof" paragraph later (warn); a section titled like "Answers to reviewer(s)" / "Response to reviewers"
     (info).
- `not_applicable` when the inputs are missing (e.g. no reference section). Findings never exceed the paper text: all
  locations validated against paragraph text; invalid ones dropped and counted.
- Human decisions: `CheckDecision = { findingId, status: 'confirmed_by_human'|'dismissed_by_human', note, at }` kept
  across re-runs by finding id.

## 2. Storage

Dexie version bump with a `paperChecks` table `{ paperId, report, decisions }`; repository get/save/review; audit
`review_check`; export/import include `paperChecks` (newest of report or decision change wins, as in P3); deleted with
the paper.

## 3. UI — tab `Kiểm tra` on `/papers/:id` (after `Tổng quan`)

- Button "Chạy kiểm tra" (local, no consent, no AI) and the time of the last run; a note "Các kiểm tra tự động là thử
  nghiệm, có thể báo nhầm; hãy xác nhận hoặc bỏ qua từng mục."
- One card per check: Vietnamese label, status Badge (Đạt / Cảnh báo / Không đạt / Không áp dụng, icon + text), summary
  ("12 trích dẫn, 2 thiếu tài liệu tham khảo"), the false-positive notes in a details element, and the findings list:
  message, quoted location(s) with paragraph id (click → map scrolled to that paragraph with the span highlighted), Xác
  nhận / Bỏ qua / Hoàn tác (audited), dismissed shown struck in a collapsed "Đã bỏ qua" group.
- Overview tab: a small "Kiểm tra" row with counts per status linking to the tab.
- `DESIGN.md`: document the checks tab. `docs/ROADMAP.md`: P3 ✅, P4 🟨.

## 4. Tests (IDs in names)

- One describe per check with synthetic paragraphs: positive and negative cases, edge formats (citation ranges, et al.,
  suffix letters, diacritics, `Fig.` vs `Figure`, plural acronyms, ignored acronyms, percentages vs. units, hedge vs.
  certainty pairing, statistic present suppresses the claim warning, Theorem with/without Proof), deterministic ids,
  location validation, `not_applicable`.
- Decisions survive a re-run; storage migration; export/import; delete with paper.
- UI: run checks → cards with statuses and counts; click a location navigates to the map with highlight; confirm /
  dismiss / undo; overview row counts.
- Coverage ≥ 90 % lines for `src/core/**`; all existing tests pass.
