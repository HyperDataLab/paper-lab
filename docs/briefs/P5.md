## 1. Core — `src/core/reviewPanel/`

- `LENSES`: `methods_skeptic`, `clarity_editor`, `reproducibility_auditor`, `newcomer_reader`, `limitations_ethics`, each
  with a Vietnamese label and the English lens description used in the prompt (one short paragraph each, specific to the
  lens).
- `src/core/prompts/paperReview.ts`: `PROMPT_VERSIONS.paperReview = 'paper-review-1'`; `buildPaperReviewPrompt(paper,
{ lens, sectionIds, checkSummary })` exactly per `docs/prompts/ai-review.md` §2 (system text verbatim with placeholders
  filled; user message = paper map `id | role | heading` + selected body paragraphs `id | "text"`);
  `PaperReviewOutputSchema` (Zod) per §2.
- Input size guard: estimate characters of the selected paragraphs; above 60 000 characters the plan refuses with a
  message asking to select fewer sections (no silent truncation).
- `anchorReview(output, paper)`: for each point, find `quote` in the named paragraph (exact, then whitespace / quote-mark
  normalised, case-sensitive first then insensitive); success → `{ paragraphId, start, end }` (code points); failure, or a
  paragraph id that is not a selected body paragraph → moved to `unanchored` with reason "không tìm thấy trích dẫn".
- `mergePanel(reviews)`: points from different lenses with the same paragraph and overlapping spans (or quotes with ≥ 60 %
  token overlap) merge into one item that lists all lenses, keeps the highest severity and each lens's wording.
- Metrics (§4, all local): `panelSimilarity` — TF-IDF cosine between lenses' weakness + question texts (tokenise,
  lowercase, drop stop words; Vietnamese text: split on whitespace/punctuation), returning the pairwise matrix, the mean and
  pairs above 0.8 ("trùng ý"); `anchoringRate` = anchored / all points; `templatePhrases` — 6–12-word n-grams from the
  points' Vietnamese and quoted text compared against a local store of n-grams from previous reviews of **other** papers;
  a phrase seen in ≥ 3 other papers is flagged "cụm khuôn mẫu" (store only n-gram hashes + paper ids, not text).
- Human-first: `HumanNotes = { paperId, text, writtenAt, revealedAt | null }`; the AI review stays hidden until the user
  saves notes or explicitly chooses "Bỏ qua bước này"; `agreement` = AI points whose quote/topic overlaps the human notes
  (token overlap ≥ 0.3), reported as counts, never as a score of the human.
- Decisions: each merged point can be confirmed / dismissed / undone by a human (audit `review_point`), kept across re-runs by
  a deterministic id (lens set + paragraph + span).

## 2. Provider, storage, budget

- `src/shared/llm/llmPaperReviewer.ts`: one call per selected lens (sequential), temperature 0.3 (lenses should differ),
  through the P2 request hook so every HTTP attempt counts against the run budget; estimate = number of lenses (+ repairs
  counted when they happen); consent = the whole-manuscript consent version from P2.
- Storage: Dexie version bump with `paperReviews` (`{ paperId, runs: [{ id, createdAt, lenses, sectionIds, promptVersion,
model, reviews, merged, metrics }], humanNotes, decisions }`) and `reviewNgrams` (hash, paperId); repository; audit
  `run_review`, `review_point`, `save_notes`; export/import include `paperReviews` (not `reviewNgrams`, which is rebuilt);
  deleted with the paper.

## 3. UI — tab `Phản biện AI` on `/papers/:id` (after `Kiểm tra`)

- Setup: lens checkboxes (all five on by default, Vietnamese labels with a one-line description), section checkboxes (body
  sections preselected except references/appendix), size estimate with the 60 000-character guard, call estimate, budget,
  `Chạy phản biện (AI)` (consent-gated), cancel.
- Human-first panel (shown first when no notes exist): a TextField "Nhận xét của bạn trước khi xem AI" with Save, and a
  secondary "Bỏ qua bước này"; after reveal the notes stay visible beside the AI review.
- Results: a permanent banner "Phản biện AI chỉ mang tính tham khảo: không chấm điểm, không đề xuất chấp nhận hay từ chối.";
  a metrics strip (Tỷ lệ neo trích dẫn x/y, Độ trùng ý giữa các góc nhìn mean + pairs, Cụm khuôn mẫu n, Đồng thuận với nhận
  xét của bạn n); filters by kind (Điểm mạnh, Điểm yếu, Câu hỏi, Cần bằng chứng), dimension and lens; merged point cards: kind,
  dimension, severity, lens chips, the quote (click → map scrolled to the paragraph with the span highlighted), point and
  rationale per lens, template-phrase warning, Xác nhận / Bỏ qua / Hoàn tác; a separate "Chưa xác định vị trí" list for
  unanchored points (no confirm button) and a "Không đánh giá được" list; each lens's summary; model and prompt version
  shown.
- `DESIGN.md`: document the tab. `docs/ROADMAP.md`: P4 ✅, P5 🟨.

## 4. Tests (IDs in names)

- Prompt: system text contains every rule from §2 (no rating, verbatim quote 5–40 words, no stock phrases, separate
  dimensions, no invented results, cannot judge, Vietnamese), lens description, sections provided/missing, check summary;
  no "rating" field in the schema.
- Size guard; anchoring (exact, normalised, wrong paragraph, non-body paragraph, missing quote → unanchored); merging across
  lenses; deterministic ids.
- Metrics: TF-IDF similarity on known texts (identical → 1, disjoint → 0), pairs above 0.8, anchoring rate, template phrases
  only from other papers and only hashes stored; agreement counts.
- Human-first gating; decisions kept across re-runs; provider (one call per lens, temperature, budget accounting).
- Storage migration, export/import, delete with paper.
- UI (fake client): human-first panel first; skip reveals; banner present and no rating text anywhere; metrics strip; filters;
  quote click navigates; confirm/dismiss/undo; unanchored list has no confirm; size-guard message.
- Coverage ≥ 90 % lines for `src/core/**` and `src/shared/llm/**`; all existing tests pass.
