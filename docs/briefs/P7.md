## 1. Core — `src/core/calibration/`

- Labels format (import and a downloadable template): `{ format: 'paragraph-lab-labels', version: 1, labels: [{ rater,
target: { kind: 'issue'|'check'|'point', type, textHash, quote } | { kind: 'score', dimension, textHash }, label:
'correct'|'incorrect' | rubric 0..4, note? }] }` (Zod). Targets are matched to local analyses by `textHash` + type + quote, so
  labels survive re-analysis; unmatched labels are reported, not dropped silently.
- `collectDecisions(store)`: human decisions already in the app count as labels from the rater `local` (confirmed → correct,
  dismissed → incorrect) for issues, P4 findings and P5 points.
- `precisionByType(labels)` per issue type / check id / lens: `{ correct, incorrect, n, precision, wilsonLow, wilsonHigh }` (95 %
  Wilson interval; null when n = 0).
- `calibrationStatus(stats)`: `uncalibrated` (n < 30), `reliable` (n ≥ 30 and wilsonLow ≥ 0.65), `unreliable` (n ≥ 30 and wilsonLow < 0.65).
  Named constants commented as product defaults.
- Inter-rater agreement: Cohen's kappa for two raters on binary labels and quadratic-weighted kappa on rubric levels, per type and
  dimension, with n; null when fewer than two raters overlap on a target or the expected agreement is 1.
- Score calibration: human rubric vs model rubric per dimension: MAE, signed bias (inflation), weighted kappa, n.
