when the user accepts it. No invented evidence (WR-08) — missing support goes to `needsEvidence`.

## 1. Core — `src/core/generation/`

- Input schema `GenerationInput`: `{ mainClaim: string (required), evidence: [{ id: 'e1', text, citation: string |
null }] (1–12 items), audience: 'specialist'|'general'|'student', structure: 'TS-D'|'LD'|'LDR'|'OCAR'|'auto',
preserveTerms: string[], hedging: 'keep_as_given'|'cautious' }`.
- Prompt `src/core/prompts/generation.ts`, `PROMPT_VERSIONS.generation = 'gen-1'`; `GenerationOutputSchema`:
  `{ paragraph: string, sentences: [{ text, role: SENTENCE_ROLES, evidenceIds: string[], usesClaim: boolean }],
needsEvidence: [{ note }] }` — no offsets. System prompt (English): write one English scientific paragraph that
  states the main claim and supports it **only** with the listed evidence items; cite each item's citation exactly
  as given when it is used; keep numbers, units, hedges and negation exactly; no new facts, numbers, citations,
  methods or causal claims beyond the evidence; follow the requested Schimel structure (topic sentence first for
  TS-D, etc.) and Topic–Action–Stress order with stress → topic links between sentences; tag each sentence with the
  evidence ids it uses; use `needsEvidence` when the claim needs support that is not given; rationale-free output.
- `provenance.ts`: `checkProvenance(input, output)` → per sentence and overall:
  - `numbers_from_inputs`: every number (with unit) in the draft appears in the claim or an evidence item (fail
    otherwise);
  - `citations_from_inputs`: every citation-like string appears in an evidence item's `citation` (fail);
  - `evidence_ids_valid`: tagged ids exist; a sentence that states a quantitative or empirical fact must tag at
    least one id (warn);
  - `claim_present`: at least one sentence `usesClaim` and its text contains the claim's key terms (warn);
  - `unused_evidence`: list evidence items not used (info);
  - `claim_strength`: the draft does not add certainty words (`prove`, `demonstrate conclusively`, `definitely`,
    `always`) absent from the inputs (fail); hedges present in the inputs are kept (warn);
  - `preserve_terms` (fail).
    Reuse S10 helpers where possible.
- `buildGeneration(input, output)` → `Generation = { id, input, paragraph, sentences (with code-computed spans in
the paragraph via exact search), needsEvidence, checks, promptVersion, model, createdAt }`.

## 2. Storage

`GenerationSchema`; Dexie table `generations` (version bump with migration, old data untouched); repository
`generations.create/get/list`; audit `create_generation`, `accept_generation` (enum extended, old data valid). Accepting
creates a **new Analysis** from the paragraph (`analyzeText`, title "Đoạn soạn: …", `parentAnalysisId: null`) and links
`generationId` in a new optional field `Analysis.origin = { kind: 'generated', generationId } | { kind: 'revision',
revisionId } | null` (default null; set it for S10 revisions too).

## 3. UI — module `Soạn đoạn` (`src/modules/generate`, currently a placeholder)

- Left column form: main claim (TextField multiline, required), evidence list (add / remove / reorder rows: text +
  optional citation; at least one), audience Select, structure SegmentedControl (Tự chọn / TS-D / LD / LDR / OCAR),
  hedging Select, preserve terms chips. Inline validation with `aria-describedby`.
- Centre: the generated paragraph in reading type; each sentence shows its role badge and evidence chips (`e1`, `e2`);
  hovering a chip highlights that evidence row; sentences failing provenance are underlined (critical colour + ⚠ +
  label).
- Right: provenance checks (pass / warn / fail with icon + text), unused evidence, `needs_evidence` ("Cần bằng chứng
  từ bạn").
- Actions: `Soạn đoạn (AI)` (consent-gated, cancellable), `Soạn lại`, `Sao chép`, `Dùng đoạn này` (primary; blocked
  by a failed check unless overridden in a confirmation dialog naming the failures) → creates the Analysis and opens
  Evaluate on it for evaluation.
- History lists generations; Evaluate shows "Đoạn soạn từ luận điểm" with a link back.
- `DESIGN.md`: document the Generate layout. `docs/ROADMAP.md`: S10 ✅, S11 🟨.
