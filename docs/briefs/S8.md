## 1. Schema (backward compatible, defaults keep S3–S7 records valid)

- `SentenceAnnotation`: `role` becomes `z.enum(SENTENCE_ROLES).nullable()` where `SENTENCE_ROLES =
['topic_sentence', 'development', 'lead', 'resolution', 'opening', 'challenge', 'action', 'transition',
'off_topic', 'unknown']` — parse old free strings as `null` via preprocess, never throw. Add
  `roleConfidence: number 0..1 | null` and `roleRationale: string | null` (defaults null).
- `Analysis.paragraph` (default `null`):
  `{ type: 'TS-D'|'LD'|'LDR'|'OCAR'|'UNKNOWN', confidence, typeScores: Record<type, 0..1>,
centralPoint: { sentenceId: string|null, span: Span|null, identifiability: 0|1|2|3|4, evidence: string },
unity: { offTopicSentenceIds: string[], rationale: string }, rationale: string }`.
- `Analysis.flowLinks` (default `[]`), one per adjacent pair:
  `{ fromSentenceId, toSentenceId, continuity: 'stress_to_topic'|'topic_to_topic'|'derived'|'shift',
discourseRelation: 'elaboration'|'cause'|'contrast'|'example'|'sequence'|'restatement'|'other'|'none',
linked: boolean, confidence, fromSpan: Span|null, toSpan: Span|null, rationale }`.
- `Analysis.paragraphMetrics` (default `null`, deterministic, each with numerator/denominator):
  `sentence_role_coverage`, `off_topic_sentence_count`, `stress_to_next_topic_alignment` (linked
  stress→topic pairs / analysable pairs), `unexplained_topic_shift_count` (shift with relation `none`),
  `discourse_relation_coverage` (pairs with relation ≠ `none` / pairs), `topic_continuity_pattern` counts per
  continuity value, `central_point_identifiability` (0–4).
- `versions.structurePrompt` (default `null`). `validateAnalysisSpans` also checks `paragraph.centralPoint.span`
  and `flowLinks[].fromSpan/toSpan` (invalid → null + suppressed entry, AC-04).

## 2. Core (pure) — `src/core/paragraph/`

- `src/core/prompts/paragraphStructure.ts`: `PROMPT_VERSIONS.paragraphStructure = 'para-struct-1'`;
  `buildParagraphStructurePrompt(text, annotations, context)`; `ParagraphStructureOutputSchema` (Zod). The user
  message lists each sentence `sN | "full text" | T: "…" | A: "…" | S: "…" | voice` (spans quoted from code
  offsets) plus optional context or "context not provided". The system prompt (English) explains Schimel's
  structures (TS-D topic sentence + development; LD lead + development; LDR lead, development, resolution;
  OCAR opening, challenge, action, resolution) and the roles, says: classify only, use `UNKNOWN` when no
  structure fits, give a score per type, judge each adjacent pair (does sentence N's stress connect to N+1's
  topic? which discourse relation?), never return offsets, never rewrite text, `rationale`/`evidence` in
  Vietnamese. Output: `{ type, typeScores, centralPointSentenceId|null, identifiability, evidence, roles: [{
sentenceId, role, confidence, rationale }], offTopicSentenceIds, unityRationale, pairs: [{ fromSentenceId,
toSentenceId, continuity, discourseRelation, linked, confidence, rationale }], rationale }`.
- `validateParagraphStructure(raw, text, annotations)`: unknown sentence ids dropped; pairs kept only when
  `to` is the sentence right after `from` (first duplicate wins); a missing pair becomes `continuity: 'shift'`,
  `discourseRelation: 'none'`, `linked: false`, `confidence: null`→`0` with rationale "no model output"; missing
  role → `unknown`; `type` not in the enum or top `typeScores` < 0.4 → `UNKNOWN`. Spans: `centralPoint.span` =
  that sentence's span; `fromSpan` = annotation `stressSpan` of N (fallback: last 25 % of N's tokens is **not**
  allowed — use `null`); `toSpan` = annotation `topicSpan` of N+1 (else `null`).
- `computeParagraphMetrics(...)` per §1, exact fractions with 3 decimals, `null` when the denominator is 0.
- `paragraphIssues(...)` → `Issue[]`, all `status: 'candidate'`, `findingKind: 'review_candidate'`, deterministic
  ids `${type}:${from}-${to}:${start}-${end}` (or `${type}:${sentenceId}:…`), Vietnamese `why` /
  `suggestedFix`, `sourcePrinciple` Schimel Ch. 11 (structure, central point, off-topic) or Ch. 13 (flow):
  - `FLOW_BREAK_CANDIDATE` for a pair with `linked: false` **and** `discourseRelation: 'none'` and confidence
    ≥ 0.5: **two spans** `{ ...fromSpan, role: 'stress_from', sentenceId: N }` and
    `{ ...toSpan, role: 'topic_to', sentenceId: N+1 }` (AC-05); if a span is null, use that whole sentence with
    role `sentence_from` / `sentence_to`. Severity `moderate`.
  - `UNEXPLAINED_TOPIC_SHIFT` for `continuity: 'shift'` with relation `none` that is not already a flow break
    (same two-span rule), severity `minor`.
  - `OFF_TOPIC_SENTENCE` for each off-topic sentence (whole sentence span), severity `moderate`.
  - `CENTRAL_POINT_WEAK` when `identifiability ≤ 1`: span = the central sentence if any, else the first sentence
    (role `central_point`), severity `major`.
  - No issue for `UNKNOWN` structure alone, for a topic-to-topic or derived continuity, or for a shift that has
    a discourse relation (lists / parallel structure).
- `mergeHumanDecisions(previous, next)` (move the existing judge-merge logic here or reuse it) so a re-run keeps
  `confirmed_by_human` / `dismissed_by_human` status and severity by id.
